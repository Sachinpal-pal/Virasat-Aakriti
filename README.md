# Virasat Aakriti - National Cultural & Architectural Heritage Hub
Advanced 3D Digital Revitalisation, AI Epigraphy Decryption & Real-Time National Archive Ledger built for cultural heritage preservation.

## Features
* **National Archive Explorer:** Real-time search across historical monuments and states.
* **AI Epigraphy Chatbot & Translator:** Instant multi-lingual translation of ancient scripts.
* **Immersive UI:** Glassmorphism and 3D visual effects for interactive learning.
